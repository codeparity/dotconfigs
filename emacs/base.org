* Org Directory & Agenda Setup

Keep Org documents and the brain directly inside the ~thoths~ repository.
Ensure the base directories exist and add the project pipeline to the Org agenda.

#+begin_src emacs-lisp
;; Keep Org documents and the brain directly inside the thoths repository.
(setq org-directory (expand-file-name "~/projects/thoths/docs/"))

;; Ensure the base directories exist
(unless (file-directory-p org-directory)
  (make-directory org-directory t))

;; Keep the project pipeline visible in the Org agenda.
(setq org-agenda-files
      (list (expand-file-name "projects/PROJECTS.org" org-directory)))
#+end_src
